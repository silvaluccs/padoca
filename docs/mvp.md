# MVP — Produto Mínimo Viável

O MVP do Padoca tem como objetivo oferecer uma vitrine digital simples e permitir que clientes montem e enviem pré-pedidos de forma organizada para pequenas padarias e lojas de salgados.

## Funcionalidades incluídas

- Listagem de produtos disponíveis
- Organização dos produtos por categoria
- Montagem de pedido com quantidades
- Envio do pedido via WhatsApp
- Registro básico do pedido para consulta da loja

## Fora do escopo

- Pagamento online
- Autenticação de usuários
- Sistema completo de e-commerce
- Integrações externas além do WhatsApp
